# 角色设定图生成功能说明

## 功能概述

从 moyin-creator 项目移植的专业角色设定图生成系统，支持：
- ✅ 三视图（正面、侧面、背面）
- ✅ 表情设定（多种面部表情）
- ✅ 比例设定（身体比例参考）
- ✅ 动作设定（各种姿势）
- ✅ 多种视觉风格（3D、2D、真人）
- ✅ 预览确认机制

## 使用流程

### 1. 创建角色
在全局角色面板中点击 "+" 创建新角色，填写：
- 角色名称
- 角色描述（详细的外观描述）
- 可选：上传参考图片

### 2. 生成设定图
在角色卡片上 hover，点击"生成设定图"按钮（图片图标）

### 3. 配置生成选项
- **角色描述**：详细描述角色外观特征
- **视觉风格**：选择合适的艺术风格
  - 3D风格：玄幻、美式、渲染2D等
  - 2D风格：动画、少女漫画、水墨等
  - 真人风格：电影、时尚摄影等
- **设定图内容**：勾选需要的元素
  - 三视图（推荐）
  - 表情设定
  - 比例设定
  - 动作设定

### 4. 预览与保存
- 生成完成后会显示预览
- 满意则点击"保存设定图"
- 不满意可以"重新生成"或"放弃并返回"

## 技术实现

### 前端组件

**CharacterSheetGenerator.tsx**
- 角色设定图生成器主组件
- 处理用户交互和预览逻辑

**StylePicker.tsx**
- 可复用的风格选择器组件
- 按分类展示所有可用风格

### 风格系统

**src/constants/visual-styles.ts**
- 统一的视觉风格预设库
- 包含 prompt、negativePrompt、描述等完整信息
- 支持按分类查询和风格切换

### 服务端 API

**POST /api/generate-character-sheet**
```json
{
  "prompt": "完整的生成提示词",
  "negativePrompt": "负面提示词",
  "sessionId": "用户会话ID"
}
```

返回：
```json
{
  "success": true,
  "imageUrl": "/api/images/character-sheets/char_sheet_xxx.jpg",
  "originalUrl": "https://..."
}
```

### Prompt 构建策略

1. **基础描述**：`professional character design sheet for "{角色名}", {角色描述}`
2. **内容元素**：根据用户选择拼接（三视图、表情、比例、动作）
3. **风格应用**：添加风格的 prompt tokens
4. **质量控制**：添加 `character reference sheet layout, white background, clean presentation`
5. **负面提示词**：过滤低质量、模糊、水印等

## 最佳实践

### 角色描述建议
- 详细描述外观特征（发型、发色、眼睛、服装）
- 包含标志性元素（配饰、道具）
- 描述整体气质和风格
- 示例：`一位年轻的剑客，黑色长发束成高马尾，锐利的蓝色眼睛，身穿深蓝色武士服，腰间佩戴银色长剑，气质冷峻`

### 风格选择建议
- **3D渲染2D**：适合现代动画风格，兼具3D质感和2D美感
- **3D玄幻**：适合仙侠、奇幻题材
- **2D动画**：适合传统日式动画风格
- **真人电影**：适合写实题材

### 内容选择建议
- **必选**：三视图（保证角色一致性）
- **推荐**：表情设定（丰富角色表现力）
- **可选**：比例设定（需要精确控制时）
- **可选**：动作设定（需要动作参考时）

## 与原有功能的区别

### 旧版（简陋）
- 只生成3个角度的简单图片
- 没有风格系统
- 没有预览确认
- Prompt 构建简单

### 新版（专业）
- 支持多种设定图内容组合
- 完整的风格预设系统
- 预览确认机制，避免浪费
- 专业的 Prompt 构建策略
- 更好的用户体验
