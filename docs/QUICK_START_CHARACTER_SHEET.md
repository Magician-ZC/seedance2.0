# 角色设定图生成 - 快速开始

## 5分钟上手指南

### 第一步：创建角色

1. 打开应用，切换到"角色"标签页
2. 点击右上角的 "+" 按钮
3. 填写角色信息：
   - **角色名称**：例如"林晚秋"
   - **角色描述**：详细描述外观，例如：
     ```
     一位18岁的高中女生，黑色长直发，清澈的棕色眼睛，
     身穿白色校服配格子裙，戴着黑框眼镜，气质文静优雅
     ```
4. 点击 ✓ 保存

### 第二步：生成设定图

1. 将鼠标悬停在刚创建的角色卡片上
2. 点击右上角的"生成设定图"按钮（📷 图标）
3. 进入设定图生成界面

### 第三步：配置生成选项

**角色描述**
- 可以进一步完善描述
- 添加更多细节（服装、配饰、特征）

**选择视觉风格**
- 点击风格选择器
- 推荐选择：
  - `3D渲染2D` - 现代动画风格（默认）
  - `3D玄幻` - 仙侠奇幻题材
  - `2D动画` - 传统日式动画
  - `真人电影` - 写实题材

**勾选设定图内容**
- ✅ 三视图（推荐必选）
- ✅ 表情设定（推荐）
- ⬜ 比例设定（可选）
- ⬜ 动作设定（可选）

### 第四步：生成与保存

1. 点击"生成角色设定图"按钮
2. 等待生成完成（约10-30秒）
3. 预览生成的设定图
4. 满意则点击"✓ 保存设定图"
5. 不满意可点击"🔄 重新生成"

## 常见问题

**Q: 生成失败怎么办？**
A: 检查是否配置了有效的 sessionId，在设置中填写即梦的会话ID

**Q: 生成的图片不满意？**
A: 可以：
- 完善角色描述，添加更多细节
- 尝试不同的视觉风格
- 调整设定图内容组合
- 点击"重新生成"多试几次

**Q: 如何获得更好的效果？**
A: 
- 描述要具体详细（发型、眼睛、服装、配饰）
- 包含气质描述（优雅、冷峻、活泼等）
- 选择与题材匹配的风格
- 三视图是必选项，保证角色一致性

**Q: 生成的图片保存在哪里？**
A: 保存在 `data/images/character-sheets/` 目录，通过 `/api/images/` 访问

**Q: 可以批量生成吗？**
A: 当前版本需要逐个生成，后续版本会支持批量生成

## 技巧与建议

1. **描述技巧**
   - 从整体到细节：整体气质 → 五官 → 发型 → 服装 → 配饰
   - 使用具体的颜色和材质描述
   - 避免模糊词汇（"好看"、"漂亮"），用具体特征

2. **风格选择**
   - 项目内所有角色使用同一风格，保持一致性
   - 3D渲染2D 适合大多数现代题材
   - 真人风格适合写实题材，但生成难度较高

3. **内容组合**
   - 初次生成：只选三视图+表情设定
   - 需要精确控制：添加比例设定
   - 需要动作参考：添加动作设定
   - 不要一次选太多，会影响单个元素的质量

4. **迭代优化**
   - 第一次生成后，根据效果调整描述
   - 保存满意的版本，继续尝试其他风格
   - 可以为同一角色生成多个风格的设定图
