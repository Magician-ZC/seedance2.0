# Seedance 三合一视频制作流水线

将小说/故事从零到成片的完整自动化工作流。

## 工作流总览

```
故事输入 → [阶段1] 剧本+分镜 → [阶段2] 创意优化 → [阶段3] 批量生成视频
```

## 阶段1：剧本与分镜生成

使用 Seedance2-Storyboard-Generator 的方法论。

### 输入确认

向用户确认以下参数：
1. 视觉风格（水墨/写实/动画/科幻/复古等）
2. 总集数和每集时长（默认 20集 × 15秒）
3. 画幅比例（16:9 / 9:16 / 21:9）
4. 情感基调

### 生成流程

1. 分析源材料，提取核心人物、冲突、情节
2. 生成四幕结构剧本（起承转合）
3. 创建素材编号清单：
   - C01-C99: 角色（多角度）
   - S01-S99: 场景/地点
   - P01-P99: 道具/物品
4. 为每集生成 Seedance 2.0 时间轴格式分镜脚本

### 分镜脚本格式

```
[风格描述]，[画幅比例]，[整体氛围]

0-3s画面：[镜头运动]，[场景建立]
3-6s画面：[镜头运动]，[情节发展]
6-9s画面：[镜头运动]，[高潮/冲突]
9-12s画面：[镜头运动]，[转折/过渡]
12-15s画面：[镜头运动]，[结尾/落版]

【声音】[配乐] + [音效] + [对白]
【参考】@图片1 [用途]，@图片2 [用途]
```

### 输出文件

- `[标题]_剧本.md` — 完整四幕剧本
- `[标题]_素材清单.md` — 素材生成提示词
- `[标题]_E[XX]_分镜.md` — 各集分镜脚本

## 阶段2：创意质量优化

使用 Seedance2-skill 的创意审核机制，对阶段1生成的每集分镜进行优化。

### 创意四关审核

对每集分镜脚本逐一检查：

1. **记忆点** — 观众看完能记住什么？答案是"没什么"就重写
2. **意外感** — 是否有反转、对比、夸张？全是意料之中=无聊
3. **情绪弧线** — 有没有情绪变化？紧张→释放、平静→爆发
4. **叙事变化** — 即使5秒也要有"从A到B"的变化

### 优化手段

- 调整运镜关键词（从词库中选取更有表现力的运镜）
- 增加情绪对比和视觉冲突
- 优化时间轴节奏分配
- 确保集与集之间的衔接自然

### 运镜词库参考

| 效果 | 关键词 |
|------|--------|
| 推近 | 推镜头/缓慢推近/急速推进 |
| 拉远 | 拉镜头/逐渐拉远 |
| 跟随 | 跟随镜头/跟拍 |
| 环绕 | 环绕镜头/360度旋转 |
| 升降 | 升镜头/降镜头/俯冲 |
| 特效 | 希区柯克变焦/一镜到底 |
| 手持 | 手持晃动 |

### 输出

- `[标题]_E[XX]_分镜_优化版.md` — 优化后的分镜脚本
- 每集附带创意审核评分和修改说明

## 阶段3：批量视频生成

使用 seedance2.0 Web 应用的 API 批量生成视频。

### 前置条件

1. 确保 seedance2.0 Web 服务已启动
2. 已配置有效的即梦 Session ID
3. 素材图片已生成并准备就绪

### 批量生成流程

1. 读取优化后的分镜脚本
2. 为每集准备：提示词 + 参考图片
3. 通过 `/api/batch-generate` 接口提交批量任务
4. 通过 WebSocket 实时监控生成进度
5. 从第2集开始使用视频延长功能串联

### 视频串联规则

```
片头(新生成) → E1(新生成) → E2(延长E1) → E3(延长E2) → ...
```

从第2集开始，提示词开头添加：`将@视频1延长15s`

### 限制

- 每次最多 9 张图片
- 每次最多 3 个视频（总15秒）
- 提示词建议控制在 300 字以内
- 敏感词可能导致生成失败，用二分法排查

## 快速开始

告诉我你的故事或小说内容，我会按照三个阶段依次完成：
1. 先生成剧本和分镜
2. 对每集进行创意优化
3. 准备好批量生成的参数

你也可以指定只执行某个阶段，比如"只优化这个分镜"或"只生成视频"。

## 小说转短剧工作流

完整的小说→短剧自动化流水线，通过 Web UI 的"小说转短剧"面板操作。

### 流程

```
小说文本 → 大模型分析 → 版权改造 → 角色图生成 → 分镜脚本 → 批量生成视频
```

### 步骤详解

1. **项目设置**：选择目标集数、每集时长、视觉风格、画幅比例
2. **输入小说**：粘贴小说全文（最多5万字）
3. **小说分析**：系统生成分析 Prompt，用户发送给大模型，将返回的 JSON 粘贴回来
4. **版权改造**：自动生成版权改造 Prompt，大模型返回改名后的角色和场景
5. **角色确认**：为每个主要角色调用即梦生成多角度参考图，用户确认后锁定
6. **生成脚本**：基于改造后的故事生成 Seedance 时间轴格式分镜脚本
7. **批量生成**：使用确认的角色图 + 分镜脚本批量生成视频

### 敏感词防护

- 系统内置敏感词库，每次生成前自动检查
- 生成失败时自动学习可能的敏感词（候选状态，需用户确认）
- 支持手动添加/删除敏感词
- 通过 Web UI 的"敏感词"面板管理

### 自动生图

- 参考图片不再是必填项
- 开启"自动生成"后，无参考图时自动调用即梦文生图 API
- 短剧模式下，所有角色图必须先生成并确认，确保角色一致性
